# Junshiro

Integrantes: Nicolas Yuji Tamashiro e Felipe Junji Goto.

Junshiro é uma coleção de jogos. `Jogo` representa um jogo, `JogoDigital` é
uma especialização e `ColecaoJogos` contém os jogos; por isso a relação é de
composição, não de herança.
